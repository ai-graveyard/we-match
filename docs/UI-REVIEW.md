## 已修复

- 广场搜索高度塌缩、类型筛选不等宽、列表分隔过密和悬停底色溢出圆角。
- 名片编辑的字段名被挤成竖排，多档可见性文案相互覆盖；改为带明确名称的 shadcn Select。名片预览身份同样使用可容纳完整英文的 shadcn Select。
- 个人中心和后台导航的固定等分布局压坏长标签；按内容宽度排布并允许换行。
- 组织卡片快捷操作、邀请码复制、审批按钮和成员管理动作在窄屏互相挤压；拆分信息与操作区域并允许换行。
- 组织详情标题被操作入口挤掉；标题和入口分行。
- 长链接留言撑宽整页；普通文本统一允许容器内断行。复现样例从 1808px 页面宽度恢复为 320px。
- 英文长按钮文案的高度不足；按钮最小高 44px，换行可增高，连接接受与拒绝保持等高。
- 暗色主按钮错误继承面板文字色；焦橙底始终配白字。
- 分享按钮文字被挤成竖排；分享与联系弹窗键盘焦点逃逸；关闭后未返回入口。补齐焦点约束、Escape 和滚动恢复，并兼容弹窗内旧式剪贴板回退。
- 语言切换时原生主题脚本触发 React 警告；改用 Next Script 的 beforeInteractive 策略。
- 名片页面标题重复品牌名、编辑需求页面标题仍显示发布。

- 使用生产构建检查上述页面。320px 和 1280px 页面宽度检查未再发现整页横向溢出；组织区块导航自身保留横向滚动。
- 实测筛选、搜索、排序、详情进入与返回；分享弹窗 Shift+Tab 回到末项，Escape 关闭后焦点返回分享入口。
- 暗色主按钮的计算文字颜色为白色；正常语言切换与页面浏览未出现新的浏览器错误。
- 截图检查含真实空状态与临时构造的长文本、组织审批和待处理连接。未执行真实发布、举手、接受、删除、解散组织或 Key 创建。

后续修改共用控件时，至少复查 320px 英文的名片编辑、个人中心、组织拥有者页面和连接记录；只看默认中文广场不足以发现本次问题。
